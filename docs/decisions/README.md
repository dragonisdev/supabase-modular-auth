# Architecture decisions

Use this folder for short decision records that affect multiple packages or future maintainers.

Each record should include:

- Context and constraints
- Options considered
- Decision
- Security and operational consequences
- Revisit conditions

Planned examples include the payment-provider choice (Stripe or Paytrail), Redis-backed security state, observability providers, and the first real tenancy model. Do not record a product-specific decision before the product requirements exist.
